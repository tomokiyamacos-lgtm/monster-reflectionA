モンスト反射ルート試作ツール（ホーム画面追加対応）

【重要】
iPhoneのホーム画面にアプリとして追加するには、HTTPSで公開されたWebサイトが必要です。
このZIPを解凍しただけでは「ホーム画面に追加」はできません。

【公開方法の例：GitHub Pages（無料）】
1. WindowsでGitHubにログインし、新しいPublicリポジトリを作成
2. このZIPを解凍し、中のファイル・iconsフォルダをすべてリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch → main / (root) → Save
4. 数分後に表示される https://ユーザー名.github.io/リポジトリ名/ をiPhoneのSafariで開く
5. Safariの共有ボタン →「ホーム画面に追加」→「Webアプリとして開く」が表示されたらオン → 追加

初回にオンラインで開けば、以降は基本機能をオフラインでも利用できます。
画像は端末内で処理し、外部サーバーへ送信しません。

注意：これはモンストの実際の物理演算や敵・ギミック判定を完全再現するものではない試作ツールです。
